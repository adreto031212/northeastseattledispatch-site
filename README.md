# northeastseattledispatch.com

Static landing site for the Northeast Seattle Dispatch newsletter (GitHub Pages). Generated by `site/dispatch/build.py northeastseattle` in the ai-ops repo. Edit there, rebuild, push here. The signup form posts to the n8n webhook `northeastseattle-dispatch-signup`, which creates the beehiiv subscription with custom fields; beehiiv → n8n → Follow Up Boss.
